# Invisible Cloak Using Python and OpenCV

## About the Project
This project creates an invisible cloak effect using Python and OpenCV. It captures the background and uses color detection and image masking to make a selected red-colored object appear invisible in the live webcam feed.

## Technologies Used
- Python
- OpenCV
- NumPy

## Features
- Real-time webcam video processing
- Red-color detection using HSV color space
- Background capture and replacement
- Image masking and compositing

## Requirements
Install the required libraries:

```bash
pip install opencv-python numpy
```

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Run the Python file:

```bash
python invisible_cloak.py
```

4. Allow webcam access and follow the instructions in the code.
5. Press `q` to exit the webcam window.

## Note
This project requires a computer with a working webcam. The effect depends on suitable lighting and a stable background.
